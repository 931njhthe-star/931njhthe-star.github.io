04 / MEASURED RESULTS

같은 영상 처리 작업을 CPU 기준 구현과 비교하고, 운영 검사 부하에 적용해 성능을 확인했습니다.

~40%멀티코어 CPU 대비 처리량 향상CPU-only 구현 기준
10s–100s×개별 CUDA 커널 가속연산별 측정값 · 전체 시스템 수치 아님

실제 운영 시스템에서 측정한 결과입니다. 11.2×와 약 40%는 파이프라인 처리량 비교이며, 10s–100s×는 개별 연산의 커널 비교입니다. 측정 기준이 다른 수치를 전체 시스템 성능으로 혼합하지 않았습니다.
