제약 정제 검사 영상의 GPU 가속 및 딥러닝 기반 이중 검사

산업용 제약 제품 검사 소프트웨어에서 이미지 처리 병목을 분석하고, 연산 특성에 맞춰 CPU와 GPU의 역할을 재구성했습니다. 사내에 GPU 개발 및 성능 검증 기반이 없던 환경에서 CUDA 기술 조사와 가속 가능성 검증부터 커널 구현·최적화, 실제 시스템 도입까지 주도했습니다. 선택적 GPU 가속과 비동기 처리 구조로 검사 처리량을 개선했으며, 기존 영상처리 검사에 딥러닝 기반 병렬 검사 경로를 추가하여 이중 검사 시스템으로 고도화했습니다.
