01EXECUTION

커널 실행·스케줄링

· ·

Thread/Block 구성 및 Block 수 조정

Block 크기와 Grid 크기를 조절해 SM 자원 활용과 병렬성을 개선한다. Warp는 32개 스레드이며, 레지스터와 Shared Memory 사용량에 따라 상주 Warp 수가 달라진다.

int i = blockIdx.x * blockDim.x + threadIdx.x;

면접 포인트: 왜 128/256 threads를 비교하는가? Occupancy가 높다고 항상 빠른 것은 아니므로 실제 커널 시간을 측정한다.

Branch Divergence 감소

같은 Warp 내 서로 다른 분기 경로가 실행되면 효율이 떨어질 수 있다. 조건문 자체보다 Warp 내 분기 일치 여부가 중요하다.

if (threadIdx.x < 16) { /* A */ } else { /* B */ }

면접 포인트: 분기 조건에 맞춰 작업을 그룹화할 수 있는지 검토한다. 조건을 임의로 바꾸면 결과가 달라질 수 있다.

Loop Unrolling

반복문을 펼쳐 제어 명령을 줄이고 독립 명령 실행 기회를 늘린다.

#pragma unroll
for (int i = 0; i < 4; ++i) sum += data[i];

면접 포인트: 과도한 언롤링은 레지스터 사용량과 코드 크기를 증가시킬 수 있다.

02MEMORY

메모리 접근 최적화

·

스레드별 메모리 접근 구조 최적화

Global Memory에서는 Warp의 접근 주소가 연속적이면 필요한 메모리 트랜잭션 수를 줄일 수 있다. Shared Memory에서는 서로 다른 주소가 동일 Bank에 몰리는 것을 피한다.

data[threadIdx.x]; // 연속 접근
data[threadIdx.x * 32]; // 큰 stride 접근

면접 포인트: 32비트 데이터 기준 Shared Memory의 Bank는 인덱스 mod 32로 설명할 수 있다. 동일 주소 읽기는 broadcast 예외다. 실제 영상처리에서는 x 방향 연속 접근을 우선 고려한다.

Shared Memory 활용

Block 내부에서 재사용할 데이터를 Shared Memory에 저장하여 Global Memory 접근을 줄인다.

__shared__ float tile[256];
tile[threadIdx.x] = input[i];
__syncthreads();

면접 포인트: 주변 픽셀을 반복 참조하는 필터 등에 유용하다. 동기화 비용과 Shared Memory 사용량도 고려한다.

03CONCURRENCY

동시성·데이터 이동

· · ·

CUDA Streams

같은 Stream 내부 작업은 순서대로 실행되고 서로 다른 Stream의 작업은 자원이 허용하면 중첩될 수 있다.

kernel<<<grid, block, 0, stream>>>(data);

면접 포인트: CPU 워커가 공유 작업 큐에서 이미지를 가져와 GPU에 제출하는 구조와 연결해 설명한다. Stream 수 증가가 항상 성능 향상을 보장하지는 않는다.

스레드 동기화

Block 내부 데이터 공유 시 __syncthreads()로 스레드 간 실행과 메모리 가시성을 조율한다.

tile[threadIdx.x] = input[i];
__syncthreads();

면접 포인트: Block 전체가 참여해야 하는 barrier를 일부 스레드만 실행하는 분기에 넣지 않도록 주의한다. Block 간 동기화는 별도 방식이 필요하다.

Global/Shared Memory Atomic Operations

여러 스레드가 같은 주소를 갱신할 때 원자적 연산으로 경쟁 상태를 방지한다.

atomicAdd(&histogram[value], 1);

면접 포인트: 동일 주소에 요청이 집중되면 병목이 생길 수 있다. Block별 집계 후 병합하는 방식 등을 고려한다.

CPU–GPU 데이터 전송 최적화

불필요한 전송을 줄이고 가능한 경우 비동기 복사와 커널 실행을 중첩한다.

cudaMemcpyAsync(dst, src, bytes, cudaMemcpyHostToDevice, stream);

면접 포인트: Host 메모리의 pinned 여부, 데이터 의존성, 장치의 복사 엔진 지원을 확인한다. 전송 포함 전체 처리 시간을 측정한다.
