경력

연구 엔지니어 — 고속 이미지 처리 파이프라인 개발 및 최적화

Enclony — 첨단기술연구소 | 2021년 3월 – 2025년 10월

  • 제약 제품 검사 시스템에 적용되는 고성능 CUDA/C++ 머신 비전 소프트웨어를 개발하고 최적화했습니다.
  • 연산량이 큰 작업에는 CUDA 가속을 선택적으로 적용하고, 비교적 가벼운 작업은 효율적인 CPU 처리로 유지하도록 이미지 처리 파이프라인을 재설계했습니다. CPU와 GPU 간 작업 분배도 최적화했습니다.
  • 이미지 처리량을 단일 코어 CPU 기준 대비 11.2배, 멀티코어 CPU만 사용한 구현 대비 약 40% 높였으며, 시간당 252만 장을 처리했습니다.
  • 다중 시점 표면 검사를 위해 객체당 RGB 이미지 10장(640×480)과 3D 카메라에서 얻은 높이 맵 2장을 처리했습니다.

연구원 — 딥러닝 및 컴퓨터 비전

세종대학교 — 지능형 차량 인식 시스템 연구실 | 2019년 11월 – 2020년 10월

  • 차량 탐지: 옥상에서 촬영한 영상에 YOLOv3/v4와 MobileNet-SSD를 적용해 탐지 성능을 평가했습니다. 수만~수십만 장의 추출 프레임을 정리하고 JSON/텍스트 데이터를 관리했으며, 탐지 결과 평가와 오류 분석을 수행했습니다.
  • 교통 표지판 인식: 카메라 기하와 좌표 변환을 이용해 3D-to-2D 투영 시뮬레이션을 개발했습니다. 3차원 축을 기준으로 회전한 표지판에 대해 LeNet과 SVM의 인식 성능을 평가하고 회전 각도가 정확도에 미치는 영향을 분석했습니다.

DriveFusion — 실시간 카메라·레이더 인식 및 평가

프로젝트 페이지 보기 사고 분석 페이지 보기

CARLA 기반 시스템을 독자적으로 구축했습니다. C++/CUDA TensorRT 모듈을 통한 YOLO11n 추론, 차량 추적, 레이더 보조 거리 추정, Qt 모니터링 대시보드를 통합했습니다. 9가지 날씨 및 시간대별 테스트 조건에서 공통 샘플 16,491개를 평가한 결과, 레이더 보조 추적으로 전체 거리 MAE를 5.41% 낮췄으며 레이더 보정 샘플 437개에서는 39.42% 감소했습니다.

확장 기능: 충돌 전후 영상·차량 위치·센서 타임라인을 통합하고, 대표 프레임과 센서 요약을 활용한 LLM 사고 분석 기능 구현.

기술: C++, CUDA, TensorRT, YOLO11n, Qt, CARLA, 레이더 융합, LLM 사고 분석
