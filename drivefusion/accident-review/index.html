사고 리뷰

영상, 차량 위치, 센서 변화를 함께 살펴보세요.

저장된 CARLA 데이터를 충돌 시점 중심으로 보여줍니다. 영상, 차량 위치 재구성, 센서 타임라인, 간결한 LLM 요약을 함께 확인할 수 있습니다.

주요 기능

충돌 시점을 중심으로 관련 근거를 확인합니다.

기록된 측정값, 시각적 재구성, LLM이 생성한 설명을 구분해 보여줍니다.

01 / 영상 확인

충돌 전후 장면 재생

충돌 약 8초 전부터 4초 후까지의 영상을 재생하고, 탐색과 재생 속도를 조절할 수 있습니다.

02 / 위치 재구성

차량 간 상대 위치 확인

CARLA 위치 기록으로 자차 주변 차량을 표시합니다. 표본 사이 움직임 보간은 화면 표시를 위한 값입니다.

03 / 센서 비교

센서 변화 추적

속도, IMU, 레이더, 차선, 차량, 충돌 이벤트를 같은 시뮬레이션 시간축에서 확인합니다.

04 / LLM 요약

선택한 근거를 LLM으로 요약

대표 이미지와 간결한 센서 요약으로 설명을 생성하고 저장합니다. 전체 영상은 LLM에 전달하지 않습니다.

ENGINEERING DECISIONS

기술적 문제와 해결

사고 분석 시스템 개발 과정에서 발생한 세 가지 문제와 해결 방법입니다.

01

이미지 프레임 재생 시 깜빡임

개별 프레임을 순차적으로 표시할 때 발생한 깜빡임을 동영상 변환으로 해결했습니다.

자세히 보기

문제 · 저장된 이미지 프레임을 브라우저에서 순차적으로 교체하자 화면이 깜빡이고 재생이 끊기는 문제가 발생했습니다.

해결 및 결과 · FFmpeg로 개별 이미지 프레임을 하나의 동영상으로 변환하고 브라우저의 비디오 플레이어로 재생하도록 변경했습니다. 사고 전후 영상을 연속적으로 확인할 수 있게 했습니다.

02

사고 재현 화면의 움직임 끊김

차량 위치 기록 사이에 보간을 적용해 불연속적인 움직임을 개선했습니다.

자세히 보기

문제 · 저장된 차량 위치를 기록 시점마다 그대로 표시하면 차량이 순간적으로 이동해 사고 재현 화면이 끊겼습니다.

해결 및 결과 · 인접한 위치 기록 사이의 중간 좌표를 보간하고 재생 시간에 맞춰 차량 위치를 갱신했습니다. 사고 전후의 차량 움직임을 부드럽게 재현할 수 있게 했습니다.

03

영상·센서 데이터의 시간 불일치

영상, 차량 위치, 센서 그래프를 공통 시간축으로 동기화했습니다.

자세히 보기

문제 · 영상과 차량 위치, 속도·IMU·레이더 기록의 시간 기준이 달라 같은 순간의 상황을 비교하기 어려웠습니다.

해결 및 결과 · 충돌 시점을 기준으로 공통 타임라인을 구성하고 영상 재생 시간에 따라 차량 위치와 센서 그래프를 갱신했습니다. 같은 시점의 영상과 측정값을 함께 비교할 수 있도록 구현했습니다.

로컬 데이터 → LLM 입력 근거

CARLA 세션 파일에서 LLM 요약까지

로컬 Python 서버가 선택한 녹화 폴더를 읽습니다. 대시보드와 LLM은 같은 세션 데이터 중 서로 다른 정보를 사용합니다.

01 · 불러오기저장된 세션세션 메타데이터를 기준으로 녹화 폴더 검색
02 · 찾기충돌 이벤트측정 기록에서 충돌 시점을 찾고 전후 데이터 수집
03 · 구성근거 데이터 구성대표 이미지 선택 및 센서 요약 정렬
04 · 요약LLM 설명 생성근거를 Responses API에 전달하고 결과 저장
같은 세션 데이터에서 나뉘는 두 가지 흐름: 대시보드는 카메라 프레임으로 FFmpeg 미리보기 영상을 만들고, 센서 기록을 타임라인에 표시하며, CARLA Ground Truth 위치로 차량을 재구성합니다. LLM 분석에서는 Python이 충돌 약 −3초, 충돌 시점, +2초의 이미지를 고르고 차량·IMU·레이더·차선 요약을 시간에 맞춰 함께 구성합니다. 전체 영상이 아니라 이 근거 데이터만 OpenAI Responses API에 전달합니다. 생성된 설명은 llm_analysis.json 세션 폴더에 저장됩니다.
session.json날씨, 녹화 모드 등 세션 메타데이터
measurements.jsonl카메라 경로, 충돌 이벤트, 차량 및 센서 기록
ground_truth.jsonl차량 위치 재구성에 사용하는 CARLA 데이터
Python 로컬 서버FFmpeg 미리보기 영상OpenAI Responses API세션별 JSON 캐시
