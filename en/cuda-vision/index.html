03 / PERFORMANCE ENGINEERING

Profile first, then remove
pipeline bottlenecks

I improved effective pipeline throughput by examining CPU work, memory transfers, synchronization, and GPU utilization together—not just individual kernel speed.

01 · PROFILE

Measure bottlenecks

Used Nsight Systems and Nsight Compute to inspect CPU/GPU execution and kernel behavior, then selected operations with meaningful acceleration potential.

Nsight SystemsNsight ComputeLatency Analysis
02 · ALLOCATE

Schedule and overlap work

Kept lightweight operations on CPU and assigned parallel workloads to GPU. Adjusted multithreaded CPU processing and CUDA streams to reduce idle time.

CPU MultithreadingCUDA StreamsAsync Execution

Adjusted kernel launch configuration and data access patterns, and iteratively reviewed global/shared/constant memory usage and occupancy.
